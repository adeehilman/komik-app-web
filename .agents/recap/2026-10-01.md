## Pelajaran untuk agent berikutnya

- **Build lolos ≠ fitur jalan.** Validasi GraphQL ke skema dan uji ke server sebelum mengklaim selesai.
- **Catatan "sumber: URL" bukan bukti** bentuk argumen. Cek tipe input lewat introspection / `@skip(if:true)`.
- **Plan untuk model kecil:** tulis kode lengkap, pastikan setiap teks "cari" unik di filenya (cek dengan
  `grep -cF`), dan sebutkan urutan bila satu teks adalah substring teks lain.
- **Model kecil bekerja baik dengan plan sempit:** satu file, satu baris, perintah verifikasi eksplisit, larangan
  eksplisit, titik STOP. W-13 lulus pada percobaan pertama dengan pola ini.
- Repo publik: jangan tulis IP publik, email, nama host tailnet, domain pribadi.
