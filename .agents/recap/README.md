# Recap per sesi

Satu file per hari kerja: `YYYY-MM-DD.md` (tambah `-2`, `-3` bila ada beberapa sesi di hari yang sama).

**Agent di percakapan baru:** baca recap **terbaru** dulu (paling bawah di daftar), lalu bagian "Terbuka / menunggu"-nya.
Recap = riwayat & konteks; kondisi yang berlaku tetap `../status.md` dan `../decisions.md` — kalau bertentangan, yang itu menang.

Isi tiap recap: ringkasan, kronologi, pelajaran untuk agent berikutnya, tabel "Terbuka / menunggu".
Ditulis oleh pemilik/senior di akhir sesi (agent eksekutor read-only).
